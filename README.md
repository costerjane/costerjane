# costerjane

Utilities for SMILE UVI analysis.

## UVI polar (MLAT/MLT) remapping

See [`scripts/uvi_polar/README.md`](scripts/uvi_polar/README.md) for remapping
public EMDS UVI quicklook frames onto a north-pole MLAT/MLT map and building a
movie.

**Note:** Public UVI QL for 2026-10-10 covers only ~00:00–05:06 UT (no 12–24 UT
data in the public archive).
